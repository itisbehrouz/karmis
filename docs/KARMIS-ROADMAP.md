# KARMİS V2 Product Roadmap

## 1. Vision Statement

Transform KARMİS into the standard open-source decision engine for professional career trajectory management.
Every analysis must produce a decision, a reason, and a verified action.

## 2. Release Phases

### V1.0 (Completed)
- CLI evaluator for job postings.
- 8-section Markdown reports.
- Flat-file CSV tracking.
- Standalone SVG company bar charts.

### V2.0 (Current Release)
- Transition to Personal Career Decision Engine.
- Structured Career DNA and Target Career State models.
- 11-category domain-neutral skill taxonomy.
- Granular Skill Gap Engine with rating tiers.
- Multi-dimensional job analysis across 11 dimensions.
- 3-state decisions (`APPLY`, `PASS`, `MAYBE`).
- 17-indicator expanded risk engine.
- First-class Evidence Wallet with requirement verification.
- Next Best Move recommendation engine.
- Actionable 30 / 60 / 90 day plans.
- 8-path Career Scenario Simulator and salary trajectories.
- SQLite persistence with versioned migrations.
- Complete CLI expansion and web dashboard upgrade.
- Comprehensive test suite with 100% test pass rate.

### V2.1 (Planned)
- Offline local embeddings for automatic job requirement parsing.
- Advanced interview rehearsal transcript recorder.
- PDF export integration without browser dependencies.

### V3.0 (Future Scope)
- Multi-user local workspace profiles.
- Automated cadence reminder daemon for scheduled check-ins.
- Cross-platform desktop packaging via Tauri.
